# Track2 评测器

日期：2026-10-23。发布版本：**0.3.5**。
当前赛题为 **30 case × 5 seed = 150 episode**。选手计算预算 **300 秒**，
工具服务时间不计入计算预算；`run()` 总墙钟上限 **600 秒**，包含工具服务时间。
控制预算为 **400 步 / 20 秒仿真 / 200 次工具调用**，单个动作超时 **5 秒**。
正式观测为固定与腕部两路 RGB。

`track2_judge` 提供正式入口、物理场景、沙箱、评分与结果门禁。
`judge_private` 包含当前 30 case、碰撞资源和参考图，仅供裁判使用。
当前 P1 区域覆盖 P2 合法位姿的碰撞包络并外扩 2 mm。

本目录必须与 Runtime 0.3.5 和当前 casebank 配套部署。
计算预算与总墙钟分别为 300 秒和 600 秒；工具服务时间只从计算预算中扣除。
只通过官方机械臂 Tool 执行动作，公开观测为双路 RGB，不公开裁判目标几何。

工作区 `report/docs` 是现行文档，`report/delivery/current` 是唯一正式交付入口。
验证结果见该目录 `current_validation.json`；接口回归不代表抓取成功率。
