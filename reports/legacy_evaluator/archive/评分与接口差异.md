# 冻结评分与正式接口核对

两份 PDF 已重新提取并目视核对公式、容差表及重复次数，SHA 与 source_references.json 一致；原文不打包。原 Runner/Verifier/Skill 和冻结 V3 源码引用摘要同文件可查。冻结 V3 实际被调用，未改一字节。

| 项目 | 当前实际能力 | 结论 |
|---|---|---|
| P1 存在/区域 | 独立可信状态区域诊断 | 不进入冻结 V3；正式区域/容器语义待批准 |
| P2 位姿 | 原位置/旋转、任务权重及配置容差 | 冻结 V3 完全兼容；标准仿真 3 cm / 10° |
| P3 空间关系 | 明确轴/区域/接触条件的候选诊断 | 不进入 V3；凹容器等尚未实现，语义待批准 |
| P4 属性 | 哈希资产标签与实例身份诊断 | 不进入 V3；真实 TTG 属性证据未验收 |
| P5 顺序 | 可信子步检查点诊断 | 不进入 V3；恢复使用、不独立计分，正式契约待确认 |
| C1 非目标位移 | 实际本回合初态作参照，标准 2 cm | 保留原公式，实测重力位移检出 |
| C1 碰撞/禁区 | 完整 240 Hz 可信事件流，缺样拒绝评分 | 原整数计数接口兼容；允许接触、onset/entry 计数单位与区域边界尚未正式批准 |
| 完成度/部分分 | Fraction 加权，默认阈值 0.6，过阈值按 c | 原实现不变；严格成功率独立，不算排名分 |
| 总分权重 | final .50、first .20、约束 .15、效率 .10、稳定性 .05 | 原公式不变 |
| 重复/恢复 | sim 5 次，first/final 独立 reset，同 seed 初态 hash 配对，B=2 | 已实测；恢复最多 3 次尝试，不为 replan 重置物体 |
| 时间/稳定性 | 裁判实际 monotonic 用时，Tref=90，总体 pstdev | 原实现保留；是否使用仿真时钟需政策决定 |
| 异常 | 初始化/末态/可信事件缺失拒绝计分；非法动作、超时保留真实失败证据 | V3 不接执行状态，仍可能给辅助分；旧 Worker 回调失败归零与原始 V3 诊断分的映射必须批准 |
| 旧任务生成 | V3 根据位置变化 >1 cm 选择 P2 目标，再评旋转 | 仅旋转变化不触发目标选择，是原契约限制；没有偷偷修改 |
| Skill 协议 | ctrc-skill-v1 ZIP manifest、initialize/run/shutdown、受限动作 | 原生命周期已通；正式 PhyAgentOS 图文预处理/SDK/依赖/Tool schema 未全部确认 |
| 图像 | 真实 TTG001 RGB 160×120、3 reset/9 帧、传入隔离 Skill | 工程证据 PASS；官方相机姿态/分辨率/参考图流程待确认 |

公开规则明确提供首帧和文字；出题人 PDF 明确公布结构化目标契约、隐藏初态。因此批准的 target_pose 不能仅因是目标字段而擅自删除；同样不能复制私有 target_layout、初态、seed、完整套件或健康记录作为输入。当前白名单和独立公开文件哈希门禁保留这一边界，完整公开 schema 待确认。

PDF 写了 P1–P5 不代表冻结 V3 已支持：其 validate_task 明确只接受 P2。本包任何 supplemental PASS 都是诊断，不是正式总分兼容。单臂 Piper 也不实现双臂交接，不能将该任务类型标为 PASS。

本阶段只验初赛仿真链路，复赛真机迁移率/证据分和决赛答辩分未进行硬件或平台验收。
